# Changelog

## 1.1.0 — 2026-10-26

- Adds the six taxes of game v0.30.0: Stamp Duty, Withholding Tax, Requisition, That's Enough, Storage Fee, Theft Insurance Premium
- Taxes that take three or more kinds of resources (Requisition, Withholding Tax) list each resource in the breakdown; the total row shows only the repayment resource
- Storage Fee and Theft Insurance Premium list the sold items in the breakdown, with only the cash that was not paid
- Requires game v0.30.0 or later (checked on v0.30.1)

## 1.0.2 — 2026-10-08
